# Quiz Generator

Convert an existing test or quiz into a `.quiz` file. Transcribe all content **verbatim** — no rephrasing, no new questions, no edits of any kind.

## When You Are Invoked

The user has provided a path to a source file containing a quiz or test they want to convert to `.quiz` format.

---

## Step 1: Read the Source File

Choose the reading method based on file extension:

- `.txt` or `.md` → Read the file directly with the Read tool
- `.pdf` → Invoke `anthropic-skills:pdf` to extract the plain text
- `.png`, `.jpg`, `.jpeg`, `.webp` → Read the image using your vision capability

---

## Step 2: Extract Questions and Answers Verbatim

From the source material, extract:
- Every question, word for word
- Every answer option, word for word
- Which answers are marked as correct (if indicated)

**Do not rephrase, summarise, clean up formatting, or alter any text in any way.**

For each question, determine its type:
- Two options reading "True" and "False" → tag as `[tf]`
- Instructions say "select all that apply", or multiple answers are marked correct → tag as `[multi]`
- Everything else → no tag (default multiple choice, `mc`)

---

## Step 3: Handle Correct Answers

### If correct answers ARE marked in the source:
Proceed directly to Step 4. Mark correct answers with `>` and incorrect answers with `*`.

### If correct answers are NOT found:
Present this prompt to the user exactly:

```
No answer key found in the source file. How would you like to proceed?

A) Upload an answer key file
B) Use Claude-generated answers (a warning will be added to the quiz)
```

**If the user picks A (answer key):**
- Read the answer key file (same supported formats: .txt, .md, .pdf, image)
- Match answers to questions by question number or letter
- If any match is ambiguous (e.g. the key has more or fewer entries than questions found, or numbering doesn't align), stop and ask the user to clarify before writing anything
- Once all answers are matched, continue to Step 4

**If the user picks B (Claude-generated):**
- For each question, select the most likely correct answer(s) based on your knowledge
- Set a `warning` flag — the `warning:` field will be added in Step 4

---

## Step 4: Write the Output File

**Determine the output filename:**
- If the user specified a filename, use it
- Otherwise, derive from the source filename, replacing the extension with `.quiz`
  - Example: `bio-exam.pdf` → `bio-exam.quiz`
  - Example: `Chapter3Test.png` → `Chapter3Test.quiz`

**Determine the quiz title:**
- Use the title found on the source document if present
- Otherwise, use the source filename without extension

**Write to `quizzes/<filename>.quiz`** using this exact format:

```
# [Quiz title]
description: Converted from [source filename]
[warning: Answers were generated by Claude and may differ from the official key.]

---

? [Question text verbatim] [type tag if applicable]
* [Wrong answer verbatim]
> [Correct answer verbatim]
* [Wrong answer verbatim]

---
```

Rules:
- Include the `warning:` line **only** when using Claude-generated answers (Step 3, option B)
- Every question block is separated by `---`
- Wrong answers use `*`, correct answers use `>`
- For `[multi]` questions, there will be multiple `>` lines
- No blank lines within a question block between the `?` line and answer lines

---

## Step 5: Confirm

After writing the file, report:

```
Saved to quizzes/<filename>.quiz — N questions
```

Where N is the total number of questions written.
