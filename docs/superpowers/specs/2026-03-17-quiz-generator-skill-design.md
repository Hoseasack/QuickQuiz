# Quiz Generator Skill — Design Spec
**Date:** 2026-03-17
**Status:** Approved

---

## Overview

A Claude Code superpowers skill that converts existing tests and quizzes into `.quiz` files. It faithfully transcribes source material — no rephrasing, no new questions, no changes to content. Supports PDFs, images, and text-based files as input.

---

## Skill Identity

- **Name:** `quiz-generator`
- **Location:** `skills/quiz-generator/skill.md`
- **Invocation:** `Skill: quiz-generator` followed by a file path
- **Example:** *"Convert this test to a quiz: ~/Downloads/bio-exam.pdf"*

---

## Supported Input Types

| Format | Reading Method |
|--------|---------------|
| `.txt`, `.md` | Direct file read |
| `.pdf` | Via `anthropic-skills:pdf` skill (returns extracted plain text) |
| `.png`, `.jpg`, `.jpeg`, `.webp` | Claude's built-in vision |

---

## Conversion Rules

- Question text is copied **verbatim** from the source
- Answer options are copied **verbatim** from the source
- Correct answers are preserved exactly as marked in the source
- Question type is **inferred** from structure:
  - Two options "True" / "False" → `[tf]`
  - "Select all that apply" or multiple correct answers marked → `[multi]`
  - Otherwise → default multiple choice (no tag — `quiz-parser.js` treats untagged questions as `mc`)
- Output filename is derived from the source filename unless the user specifies one (e.g. `bio-exam.pdf` → `bio-exam.quiz`)
- Output is saved to `quizzes/<filename>.quiz`

---

## Conversion Flow

```
1. User invokes skill with a source file path
2. Skill reads the file:
     .txt/.md  → direct read
     .pdf      → invoke anthropic-skills:pdf
     image     → Claude vision
3. Claude extracts all questions and answers verbatim
4. Infers question types from structure
5a. Correct answers found in source:
     → Write .quiz file directly
5b. No correct answers found:
     → Prompt user:
         "No answer key found. Would you like to:
          A) Upload an answer key file
          B) Use Claude-generated answers (a warning will be added to the quiz)"
     → User picks A: read answer key file, match answers, write .quiz
     → User picks B: Claude generates answers, adds warning: field, writes .quiz
6. Save to quizzes/<filename>.quiz
7. Confirm: "Saved to quizzes/bio-exam.quiz — 24 questions"
```

---

## Answer Key Handling (Option A)

When the user provides an answer key:
- Skill reads the answer key file (same supported formats)
- Matches answers to questions by number or letter
- If matching is ambiguous or incomplete, prompts the user to clarify before writing

---

## Claude-Generated Answers (Option B)

When the user opts for Claude-generated answers:
- Claude selects the most likely correct answer(s) for each question based on its knowledge
- A `warning:` field is added to the `.quiz` preamble:

```
warning: Answers were generated by Claude and may differ from the official key.
```

- This warning is displayed as a yellow banner in the web app when the quiz is loaded

---

## Output Format

Valid `.quiz` file per the format defined in `quiz-parser.js`:

```
# [Quiz Title from source]
description: Converted from [source filename]
warning: [only present if Claude-generated answers]

---

? [Question text verbatim] [type tag if applicable]
* [Wrong answer verbatim]
> [Correct answer verbatim]
* [Wrong answer verbatim]

---
```

---

## Constraints & Non-Goals

- **No content changes** — questions and answers are transcribed exactly as found
- **No question generation** — this skill does not create new questions
- **No multi-file batch** — one source file per invocation
- **No formatting cleanup** — minor OCR artifacts or formatting quirks are preserved as-is (the user can edit the `.quiz` file manually if needed)

---

## Success Criteria

- A PDF, image, or text quiz is converted to a valid `.quiz` file with no content changes
- All three question types are correctly inferred and tagged
- Quizzes with no answer key prompt the user and handle both resolution paths cleanly
- Claude-generated answer quizzes always include the `warning:` field
- Output file passes `quiz-parser.js` validation without errors
- Confirmation message reports the output path and question count
